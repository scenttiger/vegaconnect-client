# Установка VegaConnect на macOS

Сборка **не подписана** Developer ID и **не нотаризована** Apple. macOS
по умолчанию не даст запустить «в один клик» — потребуется подтверждение
вручную. Это нормально, не признак вируса.

## Шаг 1. Скачать и распаковать

1. Скачайте `VegaConnect-<version>-universal.dmg` из артефактов CI или релиза.
2. Откройте `.dmg` двойным кликом.
3. Перетащите `VegaConnect.app` в папку **Applications**.
4. Извлеките `.dmg` (правый клик на рабочем столе → «Извлечь»).
## Шаг 2. Первый запуск

### macOS 15 Sequoia / 26 Tahoe (и новее)

Кнопки «Открыть» в диалоге больше нет — Apple её убрала.

1. Двойной клик по `VegaConnect.app` → диалог «Apple не может проверить…».
2. Нажмите **Done** (не «Move to Trash»).
3. Откройте **Системные настройки → Конфиденциальность и безопасность**.
4. Прокрутите вниз до «Безопасность» — там *«VegaConnect была заблокирована…»*.
5. Нажмите **«Всё равно открыть»** → введите пароль администратора.
6. Приложение запустится, macOS запомнит выбор.

### macOS 14 Sonoma и старше

1. Правый клик (или Control+клик) по `VegaConnect.app` в Applications.
2. В меню выберите **«Открыть»**.
3. В диалоге нажмите **«Открыть»**.
## Шаг 3. «Приложение повреждено» (Apple Silicon)

На Apple Silicon неподписанное приложение может выдавать «повреждено
и не может быть открыто». Это не повреждение, а проверка целостности.
Решение — снять флаг карантина:

1. Откройте **Терминал**.
2. Выполните:
   `sudo xattr -dr com.apple.quarantine /Applications/VegaConnect.app`
3. Введите пароль администратора.
4. Запустите приложение двойным кликом.

На Intel Mac этот шаг обычно не нужен.
## Шаг 4. Разрешения (обязательно)

Без них приложение запустится, но **не сможет управлять Mac** — не будет
картинки, мыши и клавиатуры.

**Системные настройки → Конфиденциальность и безопасность**, выдать три:

- **Запись экрана** (Screen Recording) — передача экрана.
- **Универсальный доступ** (Accessibility) — мышь/клавиатура.
- **Мониторинг ввода** (Input Monitoring) — перехват клавиатуры/мыши.

В каждом: `+` → Applications → VegaConnect.app → включить тумблер.
После добавления macOS попросит перезапустить — согласитесь.
## Шаг 5. Подключение к серверу

1. Откройте `VegaConnect.app`.
2. **⋮** (три точки) → **Настройки сети**.
3. **ID/Relay Server**: `connect.vega-it.ru` (уточните у администратора).
4. **Public Key**: ключ relay (base64) — у администратора.
5. **Apply** / **OK**.

## Шаг 6. Проверка

- В главном окне появился **ID** (9 цифр) — подключилось к ID-серверу.
- Индикатор «Ready» зелёный.

## Troubleshooting

| Симптом | Решение |
|---|---|
| «Повреждено» | `sudo xattr -dr com.apple.quarantine /Applications/VegaConnect.app` |
| «Apple не может проверить» | Безопасность → «Всё равно открыть» |
| Нет подключения | проверить ID/Relay/Key, `ping connect.vega-it.ru` |
| Нет картинки | Screen Recording (Шаг 4) |
| Мышь/клава не работают | Accessibility / Input Monitoring (Шаг 4) |
## Сборка без подписи

CI собирает с ad-hoc подписью (`codesign --sign -`), без Developer ID
и нотаризации Apple. Допустимо для внутреннего тестирования. Для
публичного распространения нужен Apple Developer ID + notarization —
отдельная задача.
